# Python Terminal Flashcard Quiz Game

A command-line trivia game built using Python that dynamically parses nested real-world JSON datasets, shuffles multiple-choice configurations, and evaluates case-insensitive user inputs.

## What I Learned Building This Project:
- Managing complex nested data configurations (Dictionaries containing Lists of Dictionaries).
- Reading text payloads natively using modern `pathlib` features.
- Parsing internal module libraries (`json.loads()` and `html.unescape()`).
- Manipulating dynamic list arrays concurrently through functional programming logic (`sorted()`).
- Implementing continuous assignment arithmetic counters (`+=`) to manage states.

## How to Run
1. Ensure you have Python installed.
2. Run `python main.py` inside the directory.
